# Support

## Getting help

1. Read [README.md](README.md) for install, MCP client config, tools, and providers.
2. Read [docs/accounts-and-gateways.md](docs/accounts-and-gateways.md) for named accounts and OmniRoute gateways.
3. Read [DISCLAIMER.md](DISCLAIMER.md) for warranty, third-party API, and cost limits.
4. Search [existing issues](https://github.com/RaviTharuma/omnisearch/issues).

There is no guaranteed SLA for community support. Maintainers respond as capacity allows.

## Before opening an issue

- Confirm you are on a recent release or `main`.
- Reproduce with a minimal config (fewest providers/keys).
- Redact all API keys, tokens, cookies, and account identifiers from logs and screenshots.
- Note whether the problem is omnisearch itself vs. a third-party API (429, auth error from vendor, empty vendor payload).

## Commercial / third-party support

omnisearch maintainers do not provide paid support for third-party search vendors. Contact those vendors for billing, quota, and API access issues.
