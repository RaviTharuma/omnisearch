## Before opening an issue

- Confirm you are on a recent release or `main` (and that you reviewed the diff yourself if security-sensitive).
- Reproduce with a minimal config (fewest providers/keys).
- Redact all API keys, tokens, cookies, and account identifiers from logs and screenshots.
- Note whether the problem is omnisearch itself vs. a third-party API (429, auth error from vendor, empty vendor payload).
- For unexpected invoices: disable keys, check vendor quotas/alerts — Project Parties do not reimburse spend.
